# Cloonex v0.1.0 — Codex project memory prototype

Cloonex stores development intent, conventions, decisions and checked feature notes locally, and exposes them through MCP. This is an early integration prototype focused on Codex.

## Try it

```bash
git clone https://github.com/sywliushaocheng/cloonex.git
cd cloonex
npm ci
npm run demo
```

Requires Node.js ≥ 20.11, npm and Git. The demo uses real stdio MCP calls and an isolated temporary database; no API key or Codex login is needed for the demo. For actual Codex setup, follow the README's installation instructions.

## Included

- Task intent, scope, conventions, checkpoints and Markdown handovers.
- Decisions with explicit provenance, checked feature notes and linked-file fingerprints.
- Candidate/confirmed preferences with global, project, stack and scene scopes.
- Server-side task policy guards and on-demand stale checks.
- English and Chinese READMEs, a reproducible example, a GIF of selected real MCP output, contribution guidance and issue templates.
- A GitHub Actions workflow for Windows/Linux and Node 20/22/24.

## Validation

Locally checked on Windows with Node.js 24: typecheck, build, all 42 existing automated tests, the standalone MCP demo and package contents. Check the repository's Actions page for hosted CI results. The demo restarts the MCP server before retrieving a saved decision and verifies that a later source edit is reported by an explicit stale check.

## Limits

Search is keyword-based. Fingerprints detect content changes, including comment edits; they do not infer semantics or automatically rewrite explanations. macOS hardware and concurrent multi-process writes have not been validated. There is no GUI, background conversation capture, team collaboration or cloud sync. This release does not publish an npm package or claim measured gains in model quality or token usage.

MIT licensed. Feedback and minimal reproducible issues are welcome in English or Chinese.
